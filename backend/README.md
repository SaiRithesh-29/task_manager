# Backend - Task Manager API

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file:

```
PORT=5000
DB_URL=mongodb://localhost:27017/taskmanager
JWT_SECRET=your_secret_key
FRONTEND_URL=http://localhost:5173
```

## Scripts

- `npm run dev` - Start with nodemon
- `npm start` - Start normally
